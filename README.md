# AioGram fork without RetryAfter errors

Attention! The repository represents some improvements to the Aiogram code and does not claim any. Use at your own risk.

The original code of Aiogram and docs is available [here](https://github.com/aiogram/aiogram).

# Installation

```shell
$ python3 -m pip install git+https://github.com/ulbwazhine/aiogram
```

# Update

```shell
$ python3 -m pip install git+https://github.com/ulbwazhine/aiogram --upgrade
```
